# Topic: r0_1_baseline_verification

## Overview
Documents the verification suite and supporting artifacts that prove the R0-1 Rust foundation baseline has capturable proto inputs, canonical crates, a runnable React frontend, and Ralph tier guidance for packet evaluation.

## Key Concepts
- Anchor checks for proto/frontend/plan documents
- Connectrpc build pipeline enforcing local proto root and embedded assets
- Canonical workspace members for domain, persistence, vcs, search, integrations
- Frontend runtime-config scripts and React 19 stack
- Agent tier definitions mapped to Ralph lanes
