# Domain: rust_foundation

## Purpose
Capture the R0-1 Rust foundation anchor work that makes yona-rust a canonical implementation reference for future Ralph packets.

## Scope
Included in this domain:
- Local proto ownership and build configuration for yona-rust
- Minimal frontend bootstrap runtime config and tests
- Agent tier guidance and Ralph packet readiness documentation
- PRD/test-spec artifacts that specify success criteria for foundation/auth-workspace/org-project packets

Excluded from this domain:
- Later packet scope beyond the R0-1 baseline
- Non-Rust foundation release decisions

## Ownership
Rust foundation delivery team

## Usage
Use this domain for capturing baseline requirements, tests, and docs that anchor future Ralph packets to the yona-rust workspace.
