# Domain: release

## Purpose
Capture release landing branch runbooks that preserve minimal-drift cherry-picks, verification sequences, and aligned provenance messaging.

## Scope
Included in this domain:
- Landing branch preparation steps and branch hygiene policies
- Verification command sequences required before docs updates
- Generated-file restoration policies and doc/provenance sync instructions
- Allowed follow-up categories (drift repair, generated-file cleanup, documentation sync)

Excluded from this domain:
- General sprint planning that lacks an explicit landing branch plan
- Broad Phase 4 or later provenance ambitions

## Ownership
Release Engineering + Provenance team

## Usage
Use this domain to locate precise branch preparations that keep PR-ready landing slices bounded and documented.
