# Domain: experimental_pilot

## Purpose
Capture exploratory pilot sidecar implementations that extend or prototype new runtime/service interaction models.

## Scope
Included in this domain:
- Experimental pilot sidecar architectures (Rust, Go, or other runtimes)
- Verification scripts, DB matrix smoke tests, and runtime config injections for these sidecars
- Lessons learned about parity between pilot runtimes and the main Go pilot

Excluded from this domain:
- Production Go pilot implementation details
- Non-pilot experimental prototypes (e.g., unrelated services)

## Ownership
Rust pilot spike team

## Usage
Use this domain to document exploratory pilot-sidecar work until the experiment is productized or archived.
