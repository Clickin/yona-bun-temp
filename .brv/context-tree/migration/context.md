# Domain: migration

## Purpose
Track the Yona migration phases, checkpoints, and gate rules that guide the bounded parity efforts.

## Scope
Included in this domain:
- Phase definitions (0A-6)
- Current checkpoint status
- Deferred feature lists
- Phase gate rules and exit criteria

Excluded from this domain:
- Implementation details of individual features outside phase descriptions

## Ownership
Migration squad

## Usage
Reference for understanding what is in scope per phase and what remains deferred.
