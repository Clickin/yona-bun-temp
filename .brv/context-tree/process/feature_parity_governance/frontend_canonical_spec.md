### Structure
SPEC.md locks the workspace into the React SPA frontend, proto, and Rust crates structure, labels the root mixed Bun/Go code as reference-only, and prescribes file-based TanStack Router routing generated from src/routes/** via routeTree.gen.ts with no alternative route tables or matchers.

### Dependencies

### Highlights
Canonical frontend routing ownership resides in yona-rust/frontend/src/routes plus routeTree.gen.ts; typing-harness spec forbids legacy route artifacts; provenance audit keeps missing features labeled deferred/gap/deviation; verification baseline includes pnpm verify:agents and cargo router_contract/db_router_contract tests tied to wave 0 exit snapshot greens.

### Rules
Frontend baseline rule: use only React SPA route modules generated from src/routes/** and routeTree.gen.ts; never reintroduce route-table.ts, STATIC_ROUTES, RouteKey, AuthWorkspaceShell, props.route.kind, manual matchers, route-kind registries, compatibility wrappers, or any TypeScript sources with the any type within yona-rust/frontend/src (excluding gen/routeTree.gen.ts and typing-harness.spec.ts). Missing features rule: mark legacy parity gaps as deferred/gap/deviation with documented owners, tests, and notes, and preserve canonical docs status banners so old stack documentation is reference-only.
