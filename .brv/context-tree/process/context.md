# Domain: process

## Purpose
Capture migration governance rules that enforce feature-parity execution and agent authority for the Yona rebuild.

## Scope
Included in this domain:
- Authority hierarchy between AGENTS.md, SPEC.md, and supporting guidance documents
- Constraints on architectural changes, new structures, and canonical tooling choices
- Process dependencies that influence enforcement, documentation, and LLM onboarding

Excluded from this domain:
- Day-to-day engineering tasks unrelated to execution authority
- Feature implementation details that do not reference governance rules

## Ownership
Migration Governance Council

## Usage
Reference this domain when confirming which documents hold execution authority and what structural constraints must be honored.
