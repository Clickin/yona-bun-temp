For every later slice, migrate one user-visible owner and its hover/focus/disabled/active and
responsive states together. In the same change, replace presentation selectors in focused E2E
with accessible role/name, stable form name/id, or visible state attributes; use a narrowly named
`data-testid` only when no semantic geometry anchor exists. Never select StyleX hashes. A fallback
module is retired only after every owned selector row has desktop and 390 px evidence.

## Incremental waves

1. Wave 0: deterministic fallback/hash/manifest, structured StyleX layers, production verifier,
   root transparent precedence pilot. Complete.
2. Wave 1: root shell, header/footer/search and anonymous/authenticated user menu; retire
   `_usermenu.less` only when all shell states pass.
3. Wave 2: Bootstrap grid, controls, nav, table/status, then overlay families, each with real route
   consumers; keep Bootstrap as one fallback unit until all families pass.
4. Wave 3: shared Yobi modules, migrating responsive counterparts with their desktop owner.
5. Wave 4: complete route families and all empty/loading/error/populated/permission states.
6. Wave 5: Markdown/content and plugin-visible surfaces; remove a plugin only with its last owner.
7. Wave 6: fallback retirement only after the complete ledger and deletion smoke are green.
