Status: current, open

## Authority And Finite Scope

This matrix materializes Stage A of
`docs/plans/2026-07-11-frontend-parity-final-closure-orchestration.md`.
Legacy structure, copy, and behavior remain authoritative in `yona-original/`;
this document is an execution ledger, not a replacement source of truth.

The finite route set is the union of:

1. every browser-facing GET route in `yona-original/conf/routes` after excluding
   `/-_-api/**`, static asset handlers, and download/raw/export responses (`129`
   controller-owned patterns, including explicitly classified redirect,
   fragment, and language-resource routes), and
2. every concrete page/state URL in the refreshed legacy HTML audit's
   `results` and `discoveredPageLinks` (`191` unique URLs).

No row is green merely because a generated React route or scanner match exists.
A row becomes green only after its applicable route-state, viewport,
context-path, and language obligations have current-HEAD E2E evidence and real
legacy/local visual review. Legacy non-2xx results remain rows until classified;
they are not silently discarded.

## Layer Codes

### Route-State Layer

Each route row names exactly one applicable state family. The family expands to
these finite states; a state may be marked inapplicable only with a legacy path,
template/controller, or live-render reason in the row's evidence note.

| Code            | Applicable route-state entries                                                                                                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ROOT`          | anonymous landing; authenticated member home; guest home; site-admin home; empty/populated/loading/error notifications; login-dialog closed/open/focus/error; search-scope navigation; footer    |
| `AUTH`          | anonymous blank form; client/server validation error; mutation failure; mutation success and redirect; already-authenticated redirect                                                            |
| `DIRECTORY`     | anonymous and authenticated; empty/populated/loading/error list; filter/search; pagination where emitted by legacy                                                                               |
| `USER_READ`     | anonymous/public viewer; authenticated self; authenticated other user; populated/empty/loading/error; permission/not-found                                                                       |
| `USER_WRITE`    | authenticated self; blank/current-value form; validation error; mutation failure/success; unauthenticated and wrong-user permission results                                                      |
| `ORG_READ`      | anonymous/public viewer; guest/member/manager/site-admin; empty/populated/loading/error; permission/not-found; tabs/filter/pagination where emitted                                              |
| `ORG_WRITE`     | organization manager/site-admin form; current/blank values; validation error; mutation failure/success; member/guest/anonymous permission results; modal where emitted                           |
| `PROJECT_READ`  | anonymous public viewer; guest/member/manager/site-admin; empty/populated/loading/error; permission/not-found; tabs/filter/search/pagination where emitted                                       |
| `PROJECT_WRITE` | member/manager/site-admin as allowed by legacy; blank/current values; validation error; mutation failure/success; guest/anonymous/wrong-role permission result; modal/editor/focus where emitted |
| `SITE_ADMIN`    | site-admin empty/populated/loading/error; filter/search/pagination where emitted; mutation modal/form success/failure where emitted; non-admin and anonymous permission results                  |

| `SAMPLE`        | exact legacy sample role/data state; permission result when unauthenticated; loading/error where the React REST boundary exists                                                                  |
| `NAV`           | redirect/action source URL; success/failure/permission result; exact destination and deep-link preservation; no independent rendered-screen comparison                                           |
| `FRAGMENT`      | legacy fragment request exercised through its owning visible screen; empty/populated/loading/error and replacement interaction; no independent full-page visual claim                            |
| `RESOURCE`      | browser-consumed non-screen resource contract, status/content/context/language behavior only; no rendered-screen visual claim                                                                    |

### Viewport, Context-Path, And Language Layers

| Code         | Applicable entries                                                                                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `V-DM`       | desktop `1366x900` and mobile `390x844`; compare containment, alignment, order, wrapping, overflow, and no-overlap where responsive rules apply                                             |
| `V-OWNER`    | no standalone page; desktop/mobile geometry is verified in the owning screen that renders the fragment                                                                                      |
| `V-NA`       | no rendered page exists; browser contract/redirect evidence replaces visual comparison                                                                                                      |
| `C-ALL`      | `/`, `/yona`, `/team/yoram`; apply the configured base exactly once to navigation, forms, redirects, assets, downloads, and Markdown links                                                  |
| `L-ALL`      | raw-key/overflow/navigation in `en-US`, `ko-KR`, `ja-JP`, `ru-RU`, `uz-UZ`; full side-by-side visual review in `en-US` and `ko-KR`; fragile navbar/form checks in `ja-JP`, `ru-RU`, `uz-UZ` |
| `L-NAV`      | all configured languages at the action source and redirect destination; no standalone route copy                                                                                            |
| `L-RESOURCE` | all configured language dictionaries/content negotiation; no standalone visual copy                                                                                                         |
