## P2/P3 Exit Criteria

P2/P3 source-pass classification means the full rendered-verification queue is now expanded into follow-up evidence requirements. It is not exhaustive audit completion. Rows leave the queue only when rendered route evidence proves parity or when a precise `gap`, `deviation`, or `deferred` record is written.
