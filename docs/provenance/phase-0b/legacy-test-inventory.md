## Notes

- This inventory is a routing aid, not a completion proof.
- Any feature claiming completion still needs a narrower provenance doc, at least one failing Red test, and a passing modern translation in the target layer.
- Where controller or model tests are missing, the corresponding legacy controller or model source must be cited explicitly in the feature doc.
- This inventory does not claim full Phase 0B exit. Remaining true blockers are organization enrollment and workspace default landing. The bounded PR/review exemplar is now landed and stays limited to open/close/reopen plus review-thread read/filter only, while fuller PR parity stays deferred.
