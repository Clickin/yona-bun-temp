# User Workspace / Public Profile Provenance

## Legacy Sources

- `yona-original/conf/routes`: `GET /:user` maps to `UserApp.userInfo(user, daysAgo, selected)`.
- `yona-original/app/controllers/UserApp.java`: `userInfo` redirects organization names, clamps/stores `daysAgo`, returns not found for missing users, collects projects/issues/PRs, and filters project-backed rows through READ ACL.
- `yona-original/app/controllers/api/UserApi.java`: `statistics(loginId)` requires login, returns empty counts for missing users, and counts authored issues/postings, assigned issues, authored comments, and issue/comment votes; `users()` and `updateUserState(loginId)` provide site-manager legacy external active-user listing and state mutation with `JsonNode.findValue("state")`, `GUEST` support, and `SITE_ADMIN` rejection.
- `yona-original/app/models/Statistics.java`: legacy JSON field names are `issue`, `posting`, `assignedIssue`, `issueComment`, `postingComment`, `issueVoter`, and `issueCommentVoter`.
- `yona-original/app/views/user/view.scala.html`: user card, `#daysAgoBtn`, `Issues / Pull Requests / Projects` tabs, `common.twoColumnModeCheckboxArea()` (`#two-column-mode-checkbox`, `#two-column-mode`), `common.showSubtasksCheckbox()` (`.show-subtasks-li`, `#toggle-show-subtasks`), `.user-box`, `.user-info-box`, `.user-stream-box`, `.post-list-wrap`, and `.user-streams.all-projects` class anchors.
- `yona-original/app/views/user/partial_projectlist.scala.html`, `partial_issues.scala.html`, `partial_pullRequests.scala.html`: legacy list row class and link structure.

## Rust Implementation

- `GET /api/v1/users/:loginId/profile` returns a public profile projection for `/:user`.
- `GET /api/v1/users/:loginId/statistics` returns the legacy user statistics count fields over the app-runtime REST surface.
- App-owned legacy external user helpers under `/-_-api/v1/**` include user statistics, default-login-page mutation, site-admin active-user listing, and site-admin user-state mutation as inventoried in `docs/provenance/legacy-external-api.md`; broader user create/export issue-list compatibility remains migrator scope.
- `frontend/src/routes/$user/route.tsx` mounts the single-segment file route and redirects organization names to `/organizations/:name`.
- `frontend/src/routes/-workspace-views.tsx` renders `PublicUserProfilePage` with the legacy user card, tab/list anchors, two-column mode checkbox shell, and show-subtasks checkbox shell without inheriting private `/me` workspace controls.
- 2026-06-25 `/me` shell correction: legacy `user/view.scala.html` does not render the temporary React dashboard sections for default landing, favorite projects, recent projects, or sign-out. `WorkspacePage` now stops rendering those bottom sections and leaves logout/default-login-page entrypoints to their legacy locations (`common/usermenu.scala.html` and `common/mySeriesMenuTab.scala.html` on my-series pages).
- 2026-06-25 `/me` user-card class correction: `WorkspacePage` now matches the legacy `.user-info-box` and `.whoami.usf-group` anchors and removes the temporary `.runtime-grid` / `.lede` output from the user card.
- 2026-06-25 `/me` stream-control correction: because legacy `/me` is the same `user/view.scala.html` shell, `WorkspacePage` now restores the `common.twoColumnModeCheckboxArea()` and `common.showSubtasksCheckbox()` anchors (`#two-column-mode`, `.two-column-mode-text`, `.show-subtasks-li`, `#toggle-show-subtasks`) instead of the temporary bare `#show-subtasks` checkbox.
- 2026-06-25 empty stream shell correction: `WorkspacePage` and `PublicUserProfilePage` now keep the legacy empty-state message plus empty list anchors for issue, pull-request, and project streams (`ul.post-list-wrap.my-issues.row-fluid`, `ul.post-list-wrap.row-fluid`, and `ul.user-streams.all-projects`) instead of dropping the list shell when the collection is empty.
- 2026-06-25 project stream shell correction: `WorkspacePage` and `PublicUserProfilePage` now render member-project rows with the legacy `partial_projectlist.scala.html` avatar column (`a.avatar-wrap.small > img`), actual project logo URL projection when present, fork-origin split icon/link, viewer-specific watch/unwatch and leave anchors, and second-column `margin-left: 10px` style instead of the temporary text-initial avatar, missing avatar column, or bare watcher-count badge.
- 2026-06-25 private `/me` visual-smoke refresh: the React workspace page no longer renders the temporary diagnostic `default landing` / `basePath` / `linked emails` / `watched projects` grid. The legacy `common/mySeriesMenuTab.scala.html` default-login-page action remains on its legacy my-series pages, while non-legacy runtime diagnostics stay out of the user-visible `/me` dashboard. Evidence: `frontend/src/wave1-auth-workspace-parity.spec.tsx`, `frontend/src/auth-workspace-shell.spec.tsx`, and Playwright smoke of signup-to-`/me` showing no console warnings/errors and no diagnostic grid.
- 2026-06-26 full UI parity subagent sweep follow-up: legacy `user/view.scala.html` renders `#daysAgoBtn` as an editable number input submitted with the selected tab form. `WorkspacePage` and `PublicUserProfilePage` now keep the input editable instead of pinning it with `readOnly`; `frontend/src/workspace-profile-i18n.spec.tsx` covers both `/me` and `/:user` render output and guards against a `readonly` regression.
- 2026-06-26 public profile email visibility follow-up: legacy `application.show.user.email` controls whether profile email addresses are visible to other viewers. `GET /api/v1/users/:loginId/profile` now preserves `profile.primaryEmailAddress` for non-self viewers when `AppRuntimeConfig.show_user_email` is true and redacts it only when false; frontend render coverage pins visible and hidden public profile states.
- 2026-06-26 user stream actor-link follow-up: legacy `partial_issues.scala.html` and `partial_pullRequests.scala.html` link user cells through `routes.UserApp.userInfo(loginId)`. Workspace/public profile issue rows now carry and render author/assignee login IDs, and PR rows carry and render contributor/receiver login IDs so the React stream links point to `/:loginId` instead of spans or `/`.
- 2026-06-26 user files location follow-up: legacy `userFiles.scala.html` renders each non-user attachment location with `RouteUtil.getUrl(containerType, containerId)`. `/api/v1/workspace/files` now resolves those location paths from the attachment container through the repository and returns base-path-aware `locationHref` plus legacy route `locationLabel`; user/user-avatar attachment locations remain blank like the legacy personal-file case.
- 2026-06-21 P4-A loading-shell i18n refresh: the public `/:user` route keeps the same bootstrapping shell and resolves legacy `common.loading` through `AppRuntimeContext.messages("common.loading", { fallback: "common.loading" })`, with focused source/render coverage in `frontend/src/user-profile-route-loading-shell-i18n.spec.tsx`.
- `crates/server/src/lib.rs` reuses existing workspace profile, issue, pull-request, and member-project projections, then filters project-backed rows by the current viewer's READ ACL. Anonymous viewers see public projects only.
- `YONA_ALLOW_ANONYMOUS_ACCESS=false` installs the global anonymous-access gate for app-runtime pages and non-auth `/api/v1` calls while preserving public auth/bootstrap/reset/verify/static entrypoints.
