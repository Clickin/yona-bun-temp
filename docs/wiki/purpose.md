# Purpose

Keep a compact working map of the Rust + React conversion so an agent can
resume a StyleX or legacy-parity sweep without rereading the whole repository.

The wiki answers four questions:

1. Which canonical source defines this behavior?
2. Which React/StyleX owner implements it?
3. Which focused WTR and provenance evidence cover it?
4. Is the remaining work migrated, unavoidable, retired, `gap`, `deviation`,
   or `deferred`?

The human-facing source of truth remains the repository. This layer is for
navigation, synthesis, and an append-only work history.
